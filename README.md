# Zero-TTT

Zero-TTT 是一个仍处于研究设计阶段的个人项目，探索如何把 MCTS 产生的搜索经验压缩进一盘棋内持续存在的神经快记忆。

项目当前没有正式代码实现。稳定的算法逻辑与会频繁变化的工程计划被刻意分开维护。
