# 路线图

状态只使用 `已完成`、`下一阶段`、`未来`，避免把研究设想写成现有功能。

## 已完成：2026-08 文档化重构

- 删除内部 MCTS、旧搜索型 self-play/replay 和 CoreLoop。
- Trainer 解耦为 `BatchSource`，增加批量推理契约和合成训练 smoke。
- 棋规对齐 Tromp–Taylor 多子自杀与 positional superko。
- KataGo v1.17.2 作为 Docker 化第三方教师/GTP 骨架。
- 快权重 LaTeX/PDF 提炼为可维护 Markdown。

## 下一阶段：离线模仿

- 设计语料 manifest，并下载、校验 g170 CC0 棋谱。
- 实现 SGF 解析、规则过滤、局面抽样和离线 `BatchSource`。
- 实现本机 KataGo 批量标注器及结果校验。
- 完成监督训练运行器、验证切分和断点恢复。
- 固定 Human-SL `rank_5k` 基准协议。

## 未来：在线对战与蒸馏

- 学生 publication 的批量纯策略自博弈。
- 持久教师任务队列、局域网 worker 和结果审计。
- 在线教师数据与离线 rehearsal 的混合数据源。
- 训练轮次调度、观测、故障恢复和数据保留策略。

## 设备升级后研究

- 历史/战略快权重。
- 搜索摘要快权重及组合方案。
- 学生模型外部搜索后端和严格的搜索版本语义。

各阶段开始前需把待办提升为单独设计；路线图不预先固定尚无实验依据的比例和阈值。
