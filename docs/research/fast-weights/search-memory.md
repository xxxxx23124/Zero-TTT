# 搜索摘要记忆

状态：未来研究。

## 假设

MCTS 或教师搜索发现的候选着、价值变化和局部变例可以在真实落子后压缩进快状态，使以后
相邻局面少走弯路。它不是保存完整树，而是学习一个有损搜索摘要。

## 搜索生命周期

1. 选择当前玩家私有快状态并冻结。
2. 用冻结 evaluator 完成整次 OpenSpiel MCTS 或读取匹配的教师 annotation。
3. 当前动作由写入前的搜索结果决定。
4. 汇总根 prior/visits、value、score、预算与有限长度变例特征。
5. 搜索结束后对当前玩家状态写入一次，版本递增。
6. 旧树和外部 evaluator cache 立即失效。

## 持久摘要

基础 trajectory 按 step 保存实际预算、根访问分布、value/score、温度与根噪声；教师摘要
保存在以 `(game_id, ply, teacher_fingerprint)` 连接的 annotation shard。快状态不保存，
训练时从真实序列与摘要确定性重算。

候选输入包括访问分布相对网络 prior 的偏移、搜索前后 value/score 修正、少量主要变例，
以及搜索配置指纹。先比较无记忆、仅增加历史、缓存上一轮 policy 和可学习快状态；只有在
相同计算预算下稳定胜出，才研究更复杂写入。
