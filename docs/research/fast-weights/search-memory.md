# 搜索摘要记忆

状态：未来研究。

## 假设

强搜索发现的候选着、价值变化和局部变例可以在真实落子后压缩进快状态，使以后相邻局面
少走弯路。它不是保存完整树，而是学习一个有损的搜索摘要。

## 搜索生命周期

1. 选择当前玩家的私有快状态并冻结。
2. 用冻结的 evaluator 完成整次搜索。
3. 当前动作由写入前的搜索结果决定。
4. 汇总根 policy、value、score、访问量和有限长度变例特征。
5. 搜索结束后对当前玩家状态写入一次。
6. 快状态版本递增，旧树和评价缓存立即失效。

对手真实落子不触发对方记忆的即时写入；等该玩家再次行动时，公共棋盘历史自然包含该着。

## 摘要候选

- 根访问分布及相对网络 prior 的偏移；
- 搜索前后 value/score 修正；
- 少量主要变例的编码，而非完整节点集合；
- 教师模型、预算和搜索配置指纹。

首先比较无记忆、仅增加历史特征、缓存上次 policy 和可学习快状态。只有快状态在相同计算
预算下稳定胜出，才值得研究更复杂的元学习写入。
