# 快权重实验与风险

状态：未来研究。

## 必要对照

- 无快状态的同参数、同数据学生。
- 更长显式历史或普通循环状态。
- 只缓存上一轮 policy/value 的非学习基线。
- 仅历史记忆、仅搜索记忆、两者组合。
- 状态冻结、随机初始化和可学习初始化。

比较时固定总训练样本、教师 visits、推理 FLOPs 和显存上限，分别报告纯策略与搜索模式。

## 指标

- 固定局面 policy/value/score 损失与纯策略对局结果；
- 同一局面在不同历史下的状态敏感性；
- 快状态范数、更新幅度、跨回合保留和黑白分歧；
- 每次落子延迟、峰值显存和搜索缓存失效率；
- 在线训练中的离线能力遗忘。

## 失败条件

- 快状态只学成常量偏置或复制当前棋盘特征；
- 搜索内状态变化导致不可复现或破坏树统计；
- 收益来自额外计算而非记忆语义；
- 私有状态发生跨玩家、跨棋局或跨模型版本污染；
- 相同预算下不如扩大慢模型或增加普通历史。

任何实现都必须可完全关闭，并能加载同结构的无快状态基线；本轮不保留旧 LaTeX/PDF，
历史内容已经提炼进本目录，原文件仍可从 Git 历史恢复。
