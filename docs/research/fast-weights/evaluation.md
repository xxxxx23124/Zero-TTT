# 快权重实验与风险

状态：未来研究。

## 必要对照

- 无快状态的同参数、同数据学生。
- 更长显式历史或普通循环状态。
- 只缓存上一轮 policy/value 的非学习基线。
- 仅历史记忆、仅搜索记忆、两者组合。
- 状态冻结、随机初始化和可学习初始化。

比较时固定 trajectory manifest、教师 visits、MCTS simulations、推理 FLOPs 和显存上限，
分别报告 raw-policy 诊断与搜索对局结果。

## 指标

- 固定局面 policy/value/score 损失与 MCTS 对局结果；
- 同一局面在不同合法历史下的状态敏感性；
- 快状态范数、更新幅度、跨回合保留和黑白分歧；
- 每次落子延迟、峰值显存和 evaluator cache 失效率；
- 在线训练中的冷启动/旧阶段能力遗忘。

## 数据验收

- burn-in 与 train 子序列不跨 `game_offsets`；burn-in 不产生 loss。
- 整段 D4 变换一致，moves 重放后状态和标签仍对应。
- annotation 精确连接 game/ply，多个教师版本可共存。
- 没有强度标签或评级未知时，基线和快权重训练均可正常采样。

## 失败条件

- 快状态只学成常量偏置或复制当前棋盘特征。
- 搜索内状态变化破坏树统计或复现性。
- 收益来自额外计算，而不是记忆语义。
- 状态跨玩家、棋局或模型版本污染。
- 相同预算下不如扩大慢模型、增加历史或提高 MCTS simulations。

任何实现必须可完全关闭，并能加载同结构无快状态基线。
