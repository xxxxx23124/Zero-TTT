# 历史与战略记忆

状态：未来研究。

## 假设

纯 Transformer 已编码固定长度棋盘历史，但没有一盘棋内持续更新的显式内部状态。一个独立
快记忆可能压缩更长历史、对手风格和计划进展，从而产生持久战略；也可能只是昂贵地重复
当前棋盘已经包含的信息。

## 候选语义

- 对局开始时，从共享、可学习的初始化模板复制黑方和白方私有状态。
- 仅在真实落子边界更新，推演中的假想节点不永久写入。
- 本方更新可读取公共棋盘历史、模型输出和本方旧状态。
- 对手的私有状态不可见；换边时选择对应玩家状态。
- 状态通过有界残差调节 policy/value，不替换慢模型主干。

## 训练边界

早期实现应采用单步精确梯度、跨真实回合截断，先控制显存。初始化模板、更新器和读取器可
学习，但每种梯度路径必须有明确开关。训练目标仍是后续 policy/value/score 等任务目标，
不能只训练状态自重建而假设会提升棋力。

## 首要问题

- 当前棋盘与最近 8 步特征是否已经足够？
- 私有状态是否真正依赖长历史，还是快速坍缩为常量偏置？
- 对弈双方状态分歧能否作为诊断，而不泄漏为额外输入？
- 状态更新的计算和显存是否优于增加主干或上下文长度？
