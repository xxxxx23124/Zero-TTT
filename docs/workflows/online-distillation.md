# 阶段二：在线对战与蒸馏

状态：未来实现。该阶段使用学生实际访问到的状态修补盲点，并保持离线能力不被快速遗忘。

## 目标循环

1. 固定一个 `slow` publication，让学生双方仅凭 policy 自博弈。
2. 从生成棋局随机抽样，并可逐步加入不确定性或新颖性优先级。
3. 把状态提交给另一台机器上的强 KataGo，执行高预算搜索。
4. 保存教师 policy、value、score、ownership 和完整教师指纹。
5. 将在线教师 batch 与离线 rehearsal batch 混合，以较小学习率更新 `fast`。
6. 按样本数更新 EMA，发布新的不可变 `slow` 后开始下一轮。

## 方法定位

学生生成状态分布、教师重新标注这些状态，属于 DAgger 风格状态聚合；教师通过搜索改进
策略再蒸馏回网络，也接近 Expert Iteration。它不是普通的静态教师 online KD。

## 不变量

- 一盘学生自博弈中不切换 publication。
- 教师标签不可只保存最终落子；必须保存可监督的分布和视角。
- 在线样本不能完全替代离线样本，混合比例必须进入运行 manifest。
- 失败、超时或教师指纹变化的任务不得静默进入训练集。
- 任何快权重状态都不能跨棋局或玩家错误共享。

本轮不实现自博弈、采样器、队列、教师 worker、混合数据源或训练调度器。
