# Human-SL 分级教师

状态：已接受的目标设计，尚未实现。该模式增加在离线模仿与学生状态蒸馏之上，不替代已有
数据来源，也不改变 Learner 的监督优化方式。

## 阶段定义

每个教师阶段的运行 manifest 必须固定：

- Human-SL `profile` 与 Human-SL 模型/主分析模型指纹；
- 低预算对战参数、高预算教学参数，以及 human policy 影响搜索的参数；
- 教学、自博弈和离线 rehearsal 的数据混合比例；
- 毕业赛的规则、贴目、开局集、随机种子、双方颜色和选着规则。

只设置 `humanSLProfile` 不足以声明搜索具备该等级。教学和对战必须绑定同一 profile，并在
manifest 中显式记录 human policy 如何影响搜索；教学访问数必须高于对战访问数。具体 rank
阶梯与访问数等待标定实验，不在架构文档中预设。

## 训练循环

1. 固定学生 slow publication，运行纯策略自博弈并保存学生实际访问的状态。
2. 当前阶段教师用高预算搜索标注 policy、value、score 和可选 ownership。
3. 将完成标注的分片与离线/旧阶段 rehearsal 交给 `BatchSource` 混合。
4. Learner 执行相同的监督更新、EMA 和 publication，不感知教师等级。
5. 固定新 publication，与同 profile 的低预算教师进行毕业赛。
6. 通过门槛后切换到更强 profile；旧阶段样本继续作为 rehearsal。

## 毕业判据

- 至少完成 400 盘有效对局，学生执黑、执白各 200 盘；无结果不计入并补局。
- 同一次评测固定 publication、教师指纹、预算、开局集、种子和选着规则。
- 学生只使用 policy 直觉，不运行 MCTS。
- 学生点胜率必须不低于 55%，且 95% Wilson 胜率下界必须高于 50%。
- 未通过只继续当前阶段，不以候选/冠军对局阻止正常 publication；晋级是教师课程门槛。

结果必须保存逐局身份、颜色、胜负和汇总统计。教师配置变化或学生 publication 变化会开启
新的评测批次，不能与旧批次拼接满足 400 盘门槛。

## 风险

Human-SL 等级是工程课程标签，不是精确人类段位保证。高预算搜索可能逐渐压过等级风格，
因此需要先标定对战棋力与教学分布，再确定实际阶梯；任何标定结果都进入 manifest 和日志。
