# 2026-08-18 至 2026-08-19 历史决策摘要

这些决定解释现有模型与训练代码的来源。搜索、自博弈与 replay 路线已由
[D-027 至 D-038](README.md)更新；历史内容不回写。

## D-020：取消竞技晋升门控

保留观测与非有限值停训，不以候选/冠军对局控制模型发布。教师毕业赛只切换课程，不阻止
正常 publication，因此不恢复旧竞技发布门控。

## D-021：fast/slow 双权重

fast 接受梯度，CPU FP32 slow 按样本数做 EMA，发布不可变 BF16 slow 快照。训练语义保留；
slow 未来驱动 OpenSpiel MCTS，而不是恢复旧内部搜索闭环。

## D-022：约 3 亿参数模型

24 层 313M 方案形成棋盘 Transformer 基础，随后被 D-026 扩容方案取代。

## D-023：配置是参数事实来源

严格、可哈希 TOML 与 checkpoint 内嵌配置的原则保留。未来搜索与数据配置仍须可哈希，但
不会恢复 schema v2 的 replay 配置。

## D-024：共享超网络与稀疏 DWA

两个可关闭实验进入默认配方；目前只有工程和显存验证，没有棋力结论。

## D-025：CPU EMA 与独立 publication

slow 固定驻留 CPU，发布文件供独立推理生命周期使用。该边界继续保留。

## D-026：默认模型扩至约 6.25 亿参数

正式配置改为 32 层、`1280×20` 注意力、`d_ff=3328`，物理 batch 16；显存验收记录见
[对应开发日志](../devlog/2026-08-19-625m-model-scale-up.md)。
