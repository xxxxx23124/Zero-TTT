# 架构决策

2026-08-20 之前的完整决策保留在 Git 历史和开发日志中。以下决定取代旧的内部 AlphaZero
闭环计划；被取代不表示相关研究没有价值。

## D-027：只维护 Docker

- **状态：** 已接受
- **决定：** 测试、训练、KataGo 构建和运维只以 Docker/Compose 为支持环境。
- **影响：** 宿主机导入失败不算项目缺陷；README 不提供非 Docker 安装步骤。

## D-028：删除内部 MCTS，采用官方 KataGo

- **状态：** 已接受
- **决定：** 不再维护 Python PUCT/MCTS。KataGo v1.17.2 提供强教师分析和独立 GTP。
- **影响：** KataGo 不加载学生 checkpoint；学生默认纯策略，未来仍可接外部搜索器。

## D-029：训练只依赖批量数据契约

- **状态：** 已接受
- **决定：** Trainer 只消费 `BatchSource`/`TrainBatch`，不依赖 replay、SGF 或教师协议。
- **影响：** 每种训练流程负责适配数据和视角，但复用同一优化、EMA 和 checkpoint。

## D-030：规则与外部资产

- **状态：** 已接受
- **决定：** 规则固定为 19×19 Tromp–Taylor；KataGo 权重由用户只读挂载并单独记录许可。
- **影响：** 旧禁止自杀数据需重新解释；仓库不自动下载或提交模型权重。

## D-031：快权重延期但保持搜索兼容

- **状态：** 已接受
- **决定：** 快权重等待设备升级。未来搜索内冻结快状态，写入后作废旧树和缓存。
- **影响：** 当前代码不预留假实现；研究语义记录在[快权重文档](../research/fast-weights/overview.md)。
